# AI OFFICE 보안 설계 · 감사 기록 (v6)

AI OFFICE 는 이 PC 의 AI 세션(제목 · 요청 · 대화 원문)을 다루고, Cloudflare 터널로 바깥에도 열려 있다.
그래서 **"로그인 안 한 사람은 소스코드를 열어 봐도 세션 정보를 못 가져간다"** 와 **"외부 시스템 토큰은 코드 · 파일에 평문으로 남지 않는다"** 를 기본 원칙으로 둔다.

## 1. 누가 무엇을 보나

| 보는 사람 | 받는 데이터 |
|---|---|
| 비로그인 | 제목 · 요청 · 폴더 · 메모 · 대화 없음. "작업 중/쉬는 중" 같은 일반 문구와 지어낸 캐릭터 이름만 (`server/redact.mjs`) |
| 등급 계정 (방문자 ~ 교수) | 세션별 정보공개 정책(항목 7개 × 최소 등급)에 맞는 것만. 기본 정책은 "전부 관리자만" (`server/access.mjs`) |
| 관리자 | 전부 |

- 서버가 보는 사람마다 따로 걸러서 보낸다(SSE 포함). 브라우저 코드에는 숨길 데이터가 처음부터 오지 않는다.
- 관리 API(`isAuthed`)는 관리자만. 등급 계정은 보관본 읽기 등 허용된 GET 만.

## 2. 로그인 · 세션

- 비밀번호: scrypt 해시만 저장. 없는 아이디도 같은 계산을 해서 시간 차로 존재 여부를 못 알게.
- 로그인 토큰: **sha256 해시로만 저장**(`data/tokens.json` v2) — 파일이 새도 그대로 쓸 수 없다.
- 쿠키: HttpOnly · SameSite=Strict, 자기 페이지(Origin/Host 검사)에서만 인정. 다른 곳은 Bearer 토큰만.
- 무차별 대입: **IP 별 잠금**(5번 틀리면 30초 → 1분 → 2분 … 최대 15분), 실패를 먼저 세고 검사(동시 요청 우회 차단), 로그인 계산은 동시에 2건만, 전체 실패가 몰리면 1분 전체 잠금.
- 관리자 비밀번호는 `node server/set-admin.mjs` 로만, 12자 이상.
- `?server=` 주소 바꾸기는 **이 PC 주소(127.0.0.1 · localhost)만** 허용, 바뀌면 저장된 토큰을 버린다 (남의 서버로 토큰 · 비밀번호가 새는 것 차단).

## 3. 계정 금고 (외부 시스템 토큰)

`server/vault.mjs` — FlowBoard 칸반 토큰, 행정관리(MGM) 토큰이 여기 있다. 코드 · 설정 파일 · 배포본에 토큰이 없다.

- 계정마다 무작위 데이터키(DEK) → 항목을 **AES-256-GCM** 으로 암호화(항목 이름을 AAD 로 묶음).
- DEK 는 디스크에 평문으로 없다. ① 비밀번호 → scrypt 로 감싼 사본, ② 로그인 토큰 → HKDF 로 감싼 사본(토큰은 해시만 저장하므로 서버 파일만으로는 못 푼다).
- **로그인해야 풀린다.** 서버가 막 켜지면 잠겨 있고, 관리자가 로그인하거나 로그인된 화면이 접속하면 메모리에서 풀린다. 그 계정의 로그인이 모두 끝나면(로그아웃 · 만료) 다시 잠근다.
- 비밀번호를 바꾸면 풀려 있던 DEK 를 새 비밀번호로 다시 감싼다. 계정을 지우면 금고도 지운다.
- 처음 넣는 토큰은 "대기함"(기계 키 봉인)에 잠깐 있다가 첫 로그인 때 금고로 옮겨지고, 대기함이 비면 기계 키 파일도 지운다.
- 토큰은 **저장할 때의 API 주소(origin)에 묶인다** — 설정에서 주소를 바꿔 토큰을 다른 서버로 빼돌릴 수 없다.
- 화면 · API 응답 · 로그에 값이 나가지 않는다(상태 API 는 "있다/없다 · 열림/잠김"만).

## 5. 그 밖의 입구

- **세션 신호 입구** `/api/events` · `/api/hook/claude`: 이 PC 주소(Host)로 온 JSON 만, 터널 · 다른 사이트(Origin) · 브라우저 cross-site 요청 거부, CORS 안 열어 줌, 필드 길이 · ttl 상한 · 세션 수 상한.
- **웹훅**: https + 공개 호스트만(사설 · 루프백 · 링크로컬 IP 거부), 리다이렉트 안 따라감.
- **API 키** (`/api/v1`): scope(full · read · transfer). full 키도 정보공개 정책 · 배치 같은 관리 키는 못 바꿈.
- **보관함**: 등급 계정은 정책이 허용된 보관본만, 폴더 별칭(id 정규화)으로 정책 우회 불가, `.`/`..` 거부.
- **보관본 → 실제 세션 반영**: Claude 기록만, 작업 중 · 방금 바뀐 세션 거부, 보관 뒤 원본이 바뀌면 거부, 원본 백업 후 원자적 교체, 되돌리기.
- **정적 파일**: `public/` 밖 · `data/` · `.git` 접근 불가(경로 탐색 · 인코딩 우회 모두 403/404).
- **헤더**: CSP(`script-src 'self'`, `connect-src` 는 자기 서버만), X-Frame-Options DENY, nosniff, no-referrer, COOP, HTTPS 접속이면 HSTS.
- **화면**: 모든 외부 문자열은 `AIO.esc` 로 이스케이프, 인라인 이벤트 핸들러 없음, 색 값 · 링크 형식 검사.

## 7. 운영 수칙

- `data/` · `archive/` 는 절대 배포 · 커밋하지 않는다 (`.gitignore`).
- 토큰은 이 PC(127.0.0.1)에서 관리 센터로만 넣는다. 채팅 · 코드 · 파일에 붙여 두지 않는다.
- 토큰이 새었다고 의심되면: 그 시스템에서 토큰 폐기 → 새로 발급 → 관리 센터에서 교체.
- 서버를 새로 켠 뒤에는 관리자 화면을 한 번 열어야 금고가 풀려 칸반 자동 갱신 · 행정 연동이 동작한다.
