🔄 AI OFFICE 세션 동기화 API

서버 PC 의 Claude Code 대화를 다른 컴퓨터로 내려받아 이어서 작업하고, 다시 올려서 서버에 합치는 API 입니다.

형식은 세션 스위처의 백업 zip 그대로라서, 내려받은 파일은 스위처의 「백업 / 복원 › 가져오기」에 바로 넣을 수 있고, 스위처(또는 같은 형식을 만드는 오프라인 도구)가 만든 백업을 그대로 올리면 됩니다.

⬆️ 올리기 · 동기화

올리는 zip 형식

내려받은 것과 같은 형식입니다. 최소 요건:

  • manifest.json 의 code[] 에 대화마다 { "cli_session_id": "<uuid>", "title": "…", "transcript": true }
  • transcripts/<cli_session_id>.jsonl
  • 선택: sidecars/<id>/… · records/<id>.json · code[].transcript_folder · code[].record_name · 내려받을 때 받은 sync

zip 은 stored · deflate, zip64, UTF-8 파일 이름을 읽습니다(파이썬 zipfile · 세션 스위처 백업 그대로 됨). 암호 zip 은 안 됩니다.

POST /sync — 작은 파일 한 번에

본문에 zip 바이트를 그대로 보냅니다 (Content-Type: application/zip, Content-Length 필수, 95MB 이하).

쿼리뜻
dry_run=1미리 보기만 (반영 안 함). 처음엔 이걸로 확인하는 걸 권장
ids=a,b이 대화만 반영
overwrite=a,b이 대화는 병합 대신 올린 것으로 덮어쓰기
records=0등록 파일(Claude Desktop 사이드바)은 넣지 않기
force_live=1서버에서 지금 쓰는 중인 세션도 반영 (권장 안 함)
device=… · name=…기록용 컴퓨터 이름 · 파일 이름

응답: dry_run=1 이면 미리 보기, 아니면 반영 결과 + preview 요약. 어느 쪽이든 upload_id 가 들어 있어 나중에 되돌릴 수 있습니다.

조각 업로드 — 큰 파일

Cloudflare 터널 같은 프록시는 요청 하나에 100MB 제한이 있습니다. 큰 zip 은 조각으로 나눠 올리세요 (16~32MB 권장).
  1. POST /uploads { "size": 734003200, "name": "work.zip", "device": "LAB-PC" }
    → { "upload_id": "20261027140000-1a2b3c4d", "chunk_max": 67108864, "size": 734003200 }
  2. PUT /uploads/{upload_id}?offset=<지금까지 보낸 바이트> 본문 = 조각 바이트
    → { "received": 33554432, "size": 734003200, "complete": false } … 마지막 조각에서 "complete": true
  3. 끊겼으면 GET /uploads/{upload_id} 의 received 부터 다시 보냅니다. offset 이 틀리면 409 + received.
  4. 다 받으면 preview → 확인 → apply. 다 받지 않은 업로드는 24시간 뒤 지워집니다.

POST /uploads/{upload_id}/apply

모든 필드는 선택입니다. 비우면 zip 의 모든 대화를 병합합니다.

{
  "ids": ["1111…", "3333…"],          // 이 대화만 (없으면 전부)
  "overwrite": [],                    // 병합 대신 덮어쓸 대화
  "records": true,                    // 사이드바 등록 파일 넣기
  "force_live": false,                // 지금 쓰는 중인 세션도 (권장 안 함)
  "folder_map": { "D--lab-proj": "C--work-proj" }   // 새 대화를 둘 서버 프로젝트 폴더
}

folder_map 은 서버에 없던 새 대화를 어느 프로젝트 폴더(~/.claude/projects/<폴더>)에 둘지 정합니다. 원격 컴퓨터와 작업 경로가 다를 때 씁니다. 이미 있는 대화는 원래 있던 폴더에 합칩니다.

POST /uploads/{upload_id}/undo

{ "force": false } → { "restored": 1, "deleted": 4, "warnings": [] }

반영 전 원본(서버 data/sync/backups/<upload_id>/)으로 되돌리고, 그 반영이 새로 만든 파일(대화 · 보조 기록 · 등록 파일)은 지웁니다. 반영 기록과 백업은 최근 30건까지 남습니다.

반영한 뒤 그 대화를 서버에서 또 이어 썼으면 409 입니다 — 되돌리면 그 사이 기록이 사라지기 때문입니다. 그래도 하려면 "force": true.

🧩 합치는 규칙

세션 스위처의 복원과 같은 규칙입니다.

  • 대화(.jsonl)는 줄 단위 병합이 기본. 서버 줄 순서는 그대로, 올린 쪽에만 있는 줄을 뒤에 붙입니다. 똑같은 줄은 한 번만 → 어느 쪽 기록도 사라지지 않습니다.
    줄은 개행(\n · \r\n · \r)으로만 나누고 빈 줄은 버립니다.
  • 덮어쓰기는 overwrite 로 고른 대화만. 서버에서 그 뒤에 쓴 내용은 사라지니(백업은 남음) 꼭 필요할 때만.
  • 보조 기록(sidecars)은 서버에 없는 파일만 채웁니다. 덮으면 서버에서 이어 쓴 기록을 잃기 때문입니다.
  • 등록 파일(records)은 서버에 같은 세션 기록이 없을 때만 가장 최근에 쓰인 Claude Desktop 계정 폴더에 넣습니다. 사이드바에 안 보이면 세션 스위처의 「세션 통합연결」을 한 번 돌리세요.
  • 지금 쓰는 세션은 건너뜁니다 (서버에 살아 있거나 30초 안에 바뀐 대화).
  • 한 번에 하나만 반영합니다 (동시에 오면 423).

🗺️ 권장 작업 순서

  1. 서버에서 그 세션을 끝냅니다 (돌고 있는 채로 가져가면 양쪽이 갈라집니다).
  2. GET /bundle?ids=… → 원격 컴퓨터에서 복원 · 작업.
  3. 그동안 서버에서 같은 대화를 이어 쓰지 않습니다 (써도 병합으로 둘 다 남지만 대화가 두 갈래가 됩니다).
  4. 원격에서 백업 zip 을 만들어 dry_run / preview 로 확인 → apply.
  5. 이상하면 undo.

Python — 오프라인 소프트웨어에 붙이기

import os, requests

class AioSync:
    def __init__(self, base, key, chunk=32 * 1024 * 1024):
        self.b = base.rstrip("/") + "/api/transfer/v1"
        self.s = requests.Session(); self.s.headers["Authorization"] = "Bearer " + key
        self.chunk = chunk

    def sessions(self):
        return self.s.get(f"{self.b}/sessions").json()["sessions"]

    def download(self, ids, path):
        with self.s.get(f"{self.b}/bundle", params={"ids": ",".join(ids)}, stream=True) as r:
            r.raise_for_status()
            with open(path, "wb") as f:
                for c in r.iter_content(1 << 20): f.write(c)

    def upload(self, path, device=""):
        size = os.path.getsize(path)
        up = self.s.post(f"{self.b}/uploads", json={"size": size, "name": os.path.basename(path), "device": device}).json()
        uid, step = up["upload_id"], min(self.chunk, up["chunk_max"])
        with open(path, "rb") as f:
            off = 0
            while off < size:
                f.seek(off); data = f.read(step)
                r = self.s.put(f"{self.b}/uploads/{uid}", params={"offset": off}, data=data)
                if r.status_code == 409:                      # 끊겼다 이어 보낼 때: 서버가 받은 곳부터
                    off = r.json()["received"]; continue
                r.raise_for_status(); off = r.json()["received"]
        return uid

    def preview(self, uid):
        return self.s.post(f"{self.b}/uploads/{uid}/preview").json()

    def apply(self, uid, **opt):                              # ids · overwrite · records · force_live · folder_map
        return self.s.post(f"{self.b}/uploads/{uid}/apply", json=opt).json()

    def undo(self, uid, force=False):
        return self.s.post(f"{self.b}/uploads/{uid}/undo", json={"force": force}).json()

aio = AioSync("http://127.0.0.1:17777", "aio_xxxxxxxxxxxxxxxx")
uid = aio.upload("work-done.zip", device="LAB-PC")
p = aio.preview(uid)
for s in p["sessions"]:
    print(s["status"], s.get("add_lines"), s.get("title"))
if p["summary"]["diverged"] == 0:
    print(aio.apply(uid))
